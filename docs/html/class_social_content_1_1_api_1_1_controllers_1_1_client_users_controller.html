CancellationToken ct )
inline

Powiąż klienta z firmą

Dodaje do firmy klienta, który wcześniej sam się zarejestrował (POST /api/Auth/register-client). Klienta wskazuje się adresem e-mail użytym przy rejestracji. Klient może być powiązany z wieloma firmami, a firma z wieloma klientami.

Parametry
dtoAdres e-mail klienta.

<response code="201">Klient został powiązany z firmą.</response> <response code="400">Błędny adres e-mail.</response> <response code="401">Brak tokenu, token nieprawidłowy lub wygasły albo dostęp konta został zablokowany.</response> <response code="403">Zalogowany użytkownik nie ma roli CompanyUser.</response> <response code="404">Nie ma zarejestrowanego klienta o takim adresie e-mail.</response> <response code="409">Klient jest już powiązany z tą firmą.</response>
