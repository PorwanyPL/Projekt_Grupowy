AssignManagersDto dto,
CancellationToken ct )

Przypisz managerów do konta społecznościowego.

Ustawia pełną listę managerów, którzy mogą tworzyć posty na tym koncie (zastępuje dotychczasową). Tylko przypisani managerowie zobaczą konto i dodadzą do niego posty. Wszyscy wskazani managerowie muszą należeć do tej samej firmy co konto. Pusta lista odpina wszystkich.

Relacja jest wiele-do-wielu: jeden manager może obsługiwać kilka kont, a konto - kilku managerów.

Parametry
idIdentyfikator konta w systemie (GUID).
dtoPełna lista identyfikatorów managerów.

<response code="200">Konto po zmianie przypisań.</response> <response code="401">Brak tokenu, token nieprawidłowy lub wygasły albo dostęp konta został zablokowany.</response> <response code="403">Zalogowany użytkownik nie ma roli CompanyUser.</response> <response code="404">Konto lub któryś z managerów nie istnieje w tej firmie.</response>

CancellationToken ct )
inline

Utwórz konto społecznościowe.

Rejestruje konto platformy wraz z tokenami dostępu. Wymagane: accountId, platform (Facebook, Instagram, TikTok), externalPlatformId, accountName, accessToken i tokenExpiresAt (UTC). Para platform + accountId musi być unikalna w obrębie firmy. Dostępne tylko dla CompanyUser.

Listą managerUserIds można od razu przypisać managerów swojej firmy (jeden manager może obsługiwać wiele kont). Tokeny są zapisywane, ale API nigdy ich nie zwraca.

Parametry
dtoDane nowego konta.

<response code="201">Konto zostało utworzone; w nagłówku Location adres nowego zasobu.</response> <response code="400">Dane nie spełniają reguł walidacji (np. brak accessToken).</response> <response code="404">Któryś z wskazanych managerów nie istnieje.</response> <response code="409">Konto tej platformy o takim accountId już istnieje.</response> <response code="401">Brak tokenu, token nieprawidłowy lub wygasły albo dostęp konta został zablokowany.</response>

Usuń konto społecznościowe.

Usuwa konto i odpina jego managerów (sami managerowie pozostają). Konta, do którego są przypisane posty, nie można usunąć - najpierw zmień konto docelowe tych postów lub je usuń. Operacji nie można cofnąć.

Parametry
idIdentyfikator konta w systemie (GUID).

<response code="204">Konto zostało usunięte.</response> <response code="404">Konto o podanym identyfikatorze nie istnieje.</response> <response code="409">Do konta są przypisane posty.</response> <response code="401">Brak tokenu, token nieprawidłowy lub wygasły albo dostęp konta został zablokowany.</response>

inline

Pobierz listę kont społecznościowych.

CompanyUser dostaje wszystkie konta swojej firmy, ManagerUser - tylko konta, do których został przypisany. Wynik jest posortowany po nazwie (accountName). Wymaga tokenu JWT (nagłówek Authorization: Bearer).

Odpowiedź nigdy nie zawiera tokenów - pole hasRefreshToken informuje tylko, czy token odświeżania jest zapisany. Pola pictures i videos zawierają media z postów kierowanych na dane konto, a managerUsers - przypisanych managerów.

<response code="200">Lista kont; pusta tablica, gdy nic nie dodano.</response> <response code="401">Brak tokenu, token nieprawidłowy lub wygasły albo dostęp konta został zablokowany.</response>

Zaktualizuj konto społecznościowe.

Pełna aktualizacja danych konta. Pominięcie accessToken lub refreshToken zachowuje dotychczasową wartość tokenu, bo API nigdy nie zwraca tokenów.

Lista managerUserIds jest pełna: managerowie, których na niej brak, zostaną odpięci od konta, a podani - przypisani (przypisania do innych kont nie są zmieniane).

Parametry
idIdentyfikator konta w systemie (GUID).
dtoNowe dane konta.

<response code="200">Konto po aktualizacji.</response> <response code="400">Dane nie spełniają reguł walidacji.</response> <response code="404">Konto lub któryś z wskazanych managerów nie istnieje.</response> <response code="409">Inne konto tej platformy ma już taki accountId.</response> <response code="401">Brak tokenu, token nieprawidłowy lub wygasły albo dostęp konta został zablokowany.</response>
