Dokumentacja interfejsu SocialContent.Api.Services.IPostPublisher

Publikacja postów. Prototyp nie ma integracji z API Facebooka, Instagrama ani TikToka: publikacja sprawdza lokalnie połączenie z kontem (Validate.VerifyConnection) i, gdy jest poprawne, oznacza post jako opublikowany z symulowanym identyfikatorem zewnętrznym. Gdy połączenie jest niepoprawne, post dostaje status Failed, a administrator firmy i managerowie posta dostają powiadomienie. Więcej...

Opis szczegółowy

Publikacja postów. Prototyp nie ma integracji z API Facebooka, Instagrama ani TikToka: publikacja sprawdza lokalnie połączenie z kontem (Validate.VerifyConnection) i, gdy jest poprawne, oznacza post jako opublikowany z symulowanym identyfikatorem zewnętrznym. Gdy połączenie jest niepoprawne, post dostaje status Failed, a administrator firmy i managerowie posta dostają powiadomienie.
