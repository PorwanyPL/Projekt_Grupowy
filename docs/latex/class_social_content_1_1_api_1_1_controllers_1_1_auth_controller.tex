Zarejestruj firmę (Company\+User). 

Tworzy konto administratora firmy (nazwa firmy, e-\/mail, hasło) i od razu go loguje. Company\+User rejestruje się jako pierwszy: dopiero z jego konta można tworzyć managerów i konta społecznościowe. Managerowie nie rejestrują się sami, tworzy ich firma przez POST /\+api/\+\+Manager\+Users.

Adres e-\/mail jest identyfikatorem logowania i musi być unikalny we wszystkich rolach (firma, manager, klient); wielkość liter nie ma znaczenia. Hasło musi mieć 8-\/128 znaków, w tym małą literę, wielką literę i cyfrę. Jest przechowywane wyłącznie jako hasz PBKDF2 i nigdy nie jest zwracane.

W odpowiedzi dostajesz token JWT (access\+Token) do przekazywania w nagłówku Authorization: Bearer oraz profil z rolą Company\+User.
