Zanonimizuj managera (skasowanie danych osobowych). 

Przeznaczone dla próśb o skasowanie danych. Zamienia imię i nazwisko na "{}\+Usunięty użytkownik"{}, zastępuje opis informacją o usunięciu danych i usuwa konto logowania (e-\/mail i hasło), co natychmiast unieważnia wydane tokeny.
