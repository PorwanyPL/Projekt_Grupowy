Żądanie multipart/\+form-\/data z polem pliku "{}file"{}. Serwer sprawdza rozszerzenie (png, jpg, jpeg, gif, webp, mp4, mp3, flac), rozmiar (zdjęcia do 10 MB, wideo do 50 MB) oraz zgodność zawartości z formatem (sygnatura pliku).
