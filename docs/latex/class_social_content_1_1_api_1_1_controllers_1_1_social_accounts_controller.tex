Przypisz managerów do konta społecznościowego. 

Ustawia pełną listę managerów, którzy mogą tworzyć posty na tym koncie (zastępuje dotychczasową). Tylko przypisani managerowie zobaczą konto i dodadzą do niego posty. Wszyscy wskazani managerowie muszą należeć do tej samej firmy co konto. Pusta lista odpina wszystkich.

Relacja jest wiele-\/do-\/wielu: jeden manager może obsługiwać kilka kont, a konto -\/ kilku managerów.
